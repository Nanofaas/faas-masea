# Provenance and extraction

The experiment workspace's current solver checkout was `456cc5d`, which does not
contain the selected detailed/selective and fixed-x variants. The archived remote
ref `snapshot/dfaas-edge-experiments-ba4e5ff` points to
`d41237229b5f7827eb3fff34e0a17e48df0755d6` (Add fixed-x PG-R diagnostics).
That source contains all six methods required for this artifact.

The selected-methods report's manifest identifies `MADEA-one-shot-detailed`,
`MADEA-one-shot-selective`, `Greedy-RR` and `FaaS-MAPG-R-detailed-fixed-x`.
The two centralized references retain their names. This extraction does not
assert that every historical campaign used the same commit.

Public method names and communication-accounting names were updated together.
The auction retains detailed initialization and its selective-memory variant.
PG retains detailed initialization, randomized sweeps and fixed initial local
service. Alternative runner entry points and unrelated experiment/RL dependencies
were removed. Shared mathematical subproblems and GPU implementations needed by
the retained algorithms remain. The source code, experiment archives and original
repositories were not modified.

`source-provenance.json` records SHA-256 hashes of the upstream files from which
this artifact was extracted. The centralized runner's old catalog harness was
removed and its materialized-input loader imported directly. These hashes describe
the source files, not the edited artifact files.

`tests/upstream-reference.json` was generated by executing the original source
with the same locked Python environment on `examples/tiny`, seed 4850, two steps,
CPU local solves and one centralized solver thread. It contains objectives,
`x/y/z/r` decisions and communication counts, not timing baselines. The original
method labels in this fixture deliberately document provenance. The tests compare
against these values using the paper's new public names.
